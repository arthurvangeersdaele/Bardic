# Recueil

The Recueil of the Compagnie des bardes: `.bardic` stories shared by game masters. Browse it at https://arthurvangeersdaele.github.io/Bardic/compagnie/recueil.html

## Add your tale

1. Forge your story with the [Story builder](https://arthurvangeersdaele.github.io/Bardic/compagnie/builder.html).
2. [Upload the .bardic file here](https://github.com/arthurvangeersdaele/Bardic/upload/main/docs/recueil). GitHub creates a copy of the project in your account and opens a pull request for you.
3. A check runs on the pull request. Once it is merged, the tale appears in the Recueil.

Rules:

- one story per `.bardic` file, under 100 MB;
- only sounds you have the right to share (your own recordings, or audio under a licence that allows sharing, credited in the story description);
- a clear file name, for example `the-drowned-abbey.bardic`.

The file format is described in [BARDIC_FORMAT.md](../../BARDIC_FORMAT.md). `index.json` is rebuilt automatically, do not edit it by hand.
